StimTake FULL BUILD ZIP - OVERLAY LOADING FIX CANDIDATE
========================================================

This is a separate candidate based on the user-designated main baseline.
The original StimTake-Windows-Release-Package.zip is unchanged.

FIXES INCLUDED
- Updated Halloween overlay filename references to match the packaged HTML files.
- Updated Rust Core_Packs lookup for both the nested portable layout and the
  normal installed layout.

PACKAGE NOTES
- This archive contains the full source, overlay packs, build scripts, installer
  script, existing executable and existing installer.
- Large Rust target build caches were omitted to keep the archive practical.
  They are build artifacts and will be regenerated by Cargo.
- The existing executable and installer are preserved from the baseline and
  have NOT been rebuilt by this packaging step. Rebuild before testing the fix.

BUILD ON WINDOWS
1. Extract this ZIP.
2. Open the extracted StimTake-Windows-Release-Package folder.
3. Run BUILD-WINDOWS-RELEASE.cmd.
4. Test all Halloween overlay cards and URLs, other built-in decks, activation,
   Stop, queue, deck switching, and live OBS behavior before promoting this
   candidate.

# StimTake Website + Image Pack

## Contents
- `index.html` — responsive single-page product website
- `assets/stimtake-promo-banner.png` — generated promotional banner
- `assets/real-decks-dashboard.png` — supplied real dashboard screenshot
- `assets/real-obs-browser-source.png` — supplied real OBS Browser Source screenshot
- `assets/windows-stimtake-search.png` — supplied Windows application screenshot

## Preview
Open `index.html` in a modern browser. The page uses relative paths, so keep the `assets` folder beside it. Screenshot gallery images can be clicked to enlarge.

## Add to the repository
Copy `index.html` and the `assets` folder into the target directory, for example:
`docs/index.html` and `docs/assets/*`

Do not place this page over the root `index.html` used by the OBS overlay app.

## Publish with GitHub Pages
If the repository settings permit GitHub Pages, configure Pages to publish from the `main` branch and `/docs` folder after copying the files into `docs/`. Verify the site URL in repository Settings > Pages.

## Notes
The screenshots are actual supplied captures. The promo banner is generated artwork. The HTML notes the difference between the OBS screenshot URL on port 8790 and the README's documented port 8788; verify the actual URL for the installed app version.

Halloween 2026 Pack
===================

Contents
--------
- 20 Halloween-themed HTML overlays
- deck.json: StimTake pack manifest mapping slots 1–20 to the exact HTML filenames in this folder

Pack identity
-------------
ID: halloween_2026
Name: Halloween 2026 Pack
Type: OVERLAY_PACK
Overlay count: 20

Install / use
-------------
1. Keep the Halloween folder structure intact.
2. Place deck.json beside the 20 HTML overlays in the Halloween folder.
3. In StimTake, import or assign the HTML overlays using the pack/slot mapping in deck.json.
4. If your build supports importing a complete overlay pack, select the Halloween folder or its ZIP as directed by that build.
5. Test overlays in OBS before going live.

Safety and compatibility
------------------------
- The supplied HTML overlay files are preserved unchanged.
- deck.json only describes the pack and its slot-to-file mapping; it does not make overlays trigger from tips by itself.
- No external libraries or API behavior are declared by this manifest.
- Keep a backup before replacing an existing Halloween pack.

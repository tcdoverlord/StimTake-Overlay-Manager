StimTake obs_assets
===================

This folder is user data and is kept separate from Core_Packs.

backups/packs/   Backup copies of original or edited packs before changes.
backups/configs/ Backup copies of deck-config.json and future app settings.
custom_overlays/ Optional user-created overlays and assets.

Core_Packs is the shipped default library. Do not edit it to store user changes.
The installer creates a timestamped backup of an existing installation before
updating files. Restore a backup by copying its contents back into the install.
